# **App Name**: LinearHue

## Core Features:

- Linear Gradient Generation: Generate unique linear color gradients based on user-defined parameters or random input for color mixing and pattern creation.
- Custom Color Input UI: Allow users to select specific colors (start, end, and optional midpoints) using a color picker interface.
- Gradient Angle Control: Provide a user interface element (e.g., slider or dial) to adjust the angle of the linear gradient.
- Live Preview Display: Show a real-time, high-resolution preview of the generated linear color image as parameters are adjusted.
- Download Image: Enable users to download their generated linear color image as a high-quality PNG file.

## Style Guidelines:

- Primary color: A vibrant purple (#9F26E5) to evoke creativity and digital artistry, ensuring it stands out against the light background.
- Background color: A subtle, desaturated lavender (#F6F3F8) providing a clean, bright canvas that subtly echoes the primary hue.
- Accent color: A dynamic blue (#4D4DE6) for interactive elements and call-to-actions, providing strong contrast and visual interest.
- Body and headline font: 'Inter' (sans-serif) for its modern, clean, and highly legible appearance, suitable for a contemporary design tool.
- Use sleek, minimalist line icons to complement the app's clean and functional design, particularly for controls like download or settings.
- Employ a focused, single-page layout where the generated gradient is the central visual element, with intuitive controls discreetly placed around it.
- Subtle and smooth transitions when adjusting gradient parameters to provide immediate visual feedback and a fluid user experience.
